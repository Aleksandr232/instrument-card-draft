# Черновик карточки прибора

Локальный прототип для контент-менеджера B2B-каталога. На вход приходят данные контрольно-измерительного прибора, на выход — черновик карточки: SEO-заголовок, SEO-описание, характеристики, 3–5 поисковых запросов и короткий блок для менеджера.

Технические значения не придумываются. Их источник — только входной JSON. Пустое или отсутствующее поле помечается как «данных нет».

## Запуск

Нужен Node.js 20 или новее. Отдельные пакеты ставить не нужно.

```powershell
copy .env.example .env
npm run ai
npm start
```

`npm run ai` поднимает локальный API на [http://127.0.0.1:8080/v1](http://127.0.0.1:8080/v1). Модель — Qwen2.5 1.5B Instruct, файлы лежат в `.local` и в git не попадают. Форма открывается на [http://localhost:3000](http://localhost:3000) и ходит в этот API.

В `.env` уже указаны локальный адрес и имя модели. `OPENAI_API_KEY=local` — просто признак, что запросы к модели включены; llama-server ключ не проверяет.

Если локальный API не запущен, сервис сам собирает черновик по входным данным и пишет об этом в результат. Облачную модель можно подставить в `.env` вместо локального адреса. Файл `.env` лежит в `.gitignore`.

Проверка из терминала:

```powershell
npm test
node src/cli.js examples/manometer.json
node src/cli.js examples/thermometer.json --llm
```

Флаг `--llm` требует ключ и не подменяет сбой модели локальным текстом. `--local` всегда собирает черновик без сети.

## Как пользоваться

В форме есть название, производитель, фрагмент паспорта и список характеристик. Кнопки «Манометр» и «Термометр» подставляют два примера. Тот же JSON можно вставить вручную.

Результат показывается как Markdown, обычный текст или JSON карточки. Его можно скопировать.

Если JSON сломан, поле `specs` не объект или тело запроса пустое, сервис возвращает ошибку и не вызывает модель.

## Примеры

В задании был один заполненный образец — манометр DM 02. Описание в нём обрывается на многоточии, и сервис эту фразу не дописывает. Второй файл — учебный термометр с пустой степенью защиты, чтобы было видно пометку «данных нет».

Готовые черновики локального режима:

- [examples/results/manometer.md](examples/results/manometer.md) — заголовок 38 символов, описание около 1140
- [examples/results/thermometer.md](examples/results/thermometer.md) — в характеристиках `степень защиты: данных нет`

Заголовок манометра: «Манометр показывающий DM 02 — Манотомь». В тексте остаются только диапазон 0–1,6 МПа, класс точности 1,5, присоединение G1/2 и диаметр корпуса 100 мм.

## Промпт и решения

Системный промпт лежит в `src/prompt.js`. Модели запрещено добавлять числа, единицы, материалы, стандарты и отрасли, дописывать оборванный текст и подменять значения «более типичными». Ответ просится одним JSON-объектом. Температура 0,2.

Дальше ответ не публикуется как есть:

- таблица характеристик всегда пересобирается из `specs`; лишние поля модели отбрасываются, изменённые значения возвращаются к исходным;
- заголовок длиннее 70 символов обрезается по границе слова;
- из заголовка, описания, коммерческого блока и запросов удаляются предложения с числами и единицами, которых нет во входе;
- если после этого текста почти не осталось, подставляется локальный черновик по тем же правилам.

Локальный режим нужен, чтобы прототип запускался без ключа и не выдумывал характеристики. Поисковые запросы собираются из названия, производителя и известных значений, а не из новых артикулов.

## Ограничения

- Это одна форма и один товар за запрос. Каталога, базы, ролей и деплоя нет.
- Проверка ловит чужие числа, дроби и единицы. Она не заметит смысловую подмену без цифр, например «избыточное» давление, переписанное как «абсолютное».
- Если модель запишет то же число иначе, чем во входе (`1.50` вместо `1,5`), предложение будет снято.
- Объём 800–1200 символов при коротком паспорте набирается повторением уже известных фактов, а не новыми свойствами прибора.
- Паспорт PDF сам не разбирается: в форму или CLI нужно передать JSON.
- Что улучшать дальше: очередь карточек, загрузка паспорта, вторую проверку смысла отдельным проходом и кнопку «только локально / только модель» в форме.
